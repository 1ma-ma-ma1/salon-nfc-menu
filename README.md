# NFCメニュー

入口は LINE登録 / アプリ登録 / 口コミ / 抽選 / お知らせ の5項目です。
NFCタグに登録するURL: https://1ma-ma-ma1.github.io/salon-nfc-menu/

「抽選に参加」からlottery/へ進み、あみだくじ・ルーレット・くじ引き・たまご抽選を選択します。
4つのリンクは新GASへ直接遷移し、iframeでは埋め込みません。
旧NFC用GASと旧抽選専用GASは変更しません。

新GASを4ゲーム版へ更新し実環境で確認してから、このブランチをmainに反映します。
LINE・アプリ・口コミ・お知らせのURLは未設定のため「準備中」です。設定はconfig.jsの同じ項目を更新してください。
旧play.htmlのランダムなデモは案内ページに変更し、実際の特典として使用できないようにします。
